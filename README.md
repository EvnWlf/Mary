<h1 align="center">Mary</h1>

<p align="center">
  <b>Mary</b> es una experiencia integral de música y lectura, concebida para ser una extensión natural de tu entorno digital y diseño moderno (Fluent Design).
</p>

---

## 🚀 Características

* **Diseño Nativo Moderno:** Interfaz adaptada con soporte dinámico para temas de Windows (Claro / Oscuro) y tipografías fluidas.
* **Gestión de Música:** Escaneo automático de bibliotecas locales para organizar canciones, listas y álbumes.
* **Gestión de Lectura:** Organización inteligente de colecciones de libros digitales.
* **Experiencia de Bienvenida:** Flujo de configuración inicial interactivo y estilizado para un primer uso impecable.
